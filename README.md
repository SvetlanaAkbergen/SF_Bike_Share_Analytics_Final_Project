# SF_Bike_Share_Analytics_Final_Project
Power BI | Анализ 1,95 млн поездок велопроката Сан-Франциско (2013–2018): временные тренды, география, пользователи, качество данных и бизнес-выводы.

📥 Скачать интерактивный дашборд Power BI (.pbix)

О проекте

Интерактивный аналитический отчёт на основе около 1,95 млн поездок велопроката Сан-Франциско за 2013–2018 годы.

Разделы дашборда:

Главная — основные показатели.

Обзор — общая аналитика поездок.

Время — анализ по годам, месяцам, дням недели и часам.

География — станции и популярные маршруты.

Пользователи — сегментация, демография и качество данных.

Инструменты: Power BI, Power Query, DAX.

Для работы с интерактивным отчётом скачайте файл .pbix и откройте его в Power BI Desktop.
